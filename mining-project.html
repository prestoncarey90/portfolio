SDOH Project: Epidemiological Social Determinants of Health Analytics Engine

Epidemiological Data

Deploying Poisson regression and unsupervised K-Means clustering to decouple neighborhood poverty from systemic HIV public health disparities across NYC ZIP codes.

Executive Summary

Traditional public health models frequently default to using generic neighborhood poverty rates to explain health disparities, an approach that often hides more complex structural drivers. To test this limitation, our team architected a multi-layer analytical engine evaluating NYC HIV public health datasets (2019–2023) alongside localized Social Determinants of Health (SDOH) matrices across conformed ZIP code zones.

By implementing an offset Poisson regression model and unsupervised K-Means clustering, the engine successfully unmasked critical institutional anomalies—most notably the structural distortion caused by localized correctional populations—and demonstrated that wealth inequality (the Gini coefficient) serves as a far more potent predictor of localized health burden than income or poverty markers alone.

Technical Stack & Library Footprint

  • Core Processing Engine: Python (Pandas, NumPy)
  • Statistical Modeling: Statsmodels (Poisson GLM with log-link functions)
  • Machine Learning & Clustering: Scikit-Learn (KMeans, StandardScaler, AgglomerativeClustering)

Phase 2: Predictive Engine & The Rikers Island Unmasking

Because HIV diagnosis records are count-based outcomes rather than continuous, un-bounded variables, ordinary multiple linear regression (MLR) models can output negative predictions and distort variance indicators. We deployed a Poisson generalized linear model (GLM) featuring a log-link function.

To properly scale the counts relative to varying neighborhood boundaries, we integrated 2020 Census population records directly into the model as an offset variable, effectively treating population scale as a fixed constant while modeling the underlying case distribution.

Engineering for Causal Anomalies (The Rikers Hack)

Initial diagnostic passes revealed an massive outlier footprint at ZIP code 11370—the geographical anchor for the Rikers Island correctional facility. Because an institutional population displays fundamentally different public health patterns than standard residential zones, this single data point introduced severe skewing across our multivariable correlation matrices.

To resolve this, we engineered an explicit institutional dummy variable directly into our final statistical sweep:

  • Deviance Optimization: Incorporating the institutional control variable caused the model’s baseline Deviance metric to drop from a highly unstable 27,695 down to an incredibly tight 3,644 in the sensitivity iteration.
  • Model Validation: The final sweep achieved a statistically robust McFadden’s Pseudo R-squared of 0.3922, confirming an elite fit for real-world categorical count modeling.
  • The Gini Indicator: The finalized model proved that the Gini coefficient (income inequality) maintained a powerful, independent positive relationship with elevated case counts, even when poverty and absolute household income metrics were held fully constant.

Phase 3: Unsupervised Machine Learning Profile Clustering

To classify the 141 conformed ZIP codes based on overlapping layers of health metrics and socioeconomic context, we deployed an unsupervised K-Means clustering sequence, processing 14 continuous input features simultaneously.

Calibration & Cross-Method Validation

We tested cluster counts ranging from \(k = 2\) through \(k = 10\), evaluating them using a combined Elbow and Silhouette framework. While a simple \(k=2\) sequence offered the cleanest raw mathematical partition, we chose a 4-cluster solution to provide meaningful operational segments for real-world public health resource allocation:

Stability Verification

To prove the resulting boundaries were structural assets rather than algorithm-specific artifacts, we ran an identical validation layer using Hierarchical Agglomerative Clustering with Ward Linkage, which acts to minimize within-cluster variance during merge steps.

Cross-tabulation modeling revealed near-identical cluster assignments between K-Means (Silhouette Score: 0.31) and Hierarchical Ward linkage (Silhouette Score: 0.32), establishing complete mathematical stability before passing the data to our writing lead for reporting.
